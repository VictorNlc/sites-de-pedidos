# Sites de pedidos para restaurantes

Pedido online direto com o restaurante, sem taxa de aplicativo. O cliente monta o pedido, vê a taxa de entrega do bairro, paga no PIX e o pedido chega pronto no WhatsApp da loja.

Feito para 11 pizzarias, hamburguerias e deliveries do Rio Grande do Sul.

> O código de cada site é do restaurante e fica privado. Aqui estão os prints e os links dos sites no ar.

## O que o site faz

- Cardápio com fotos, tamanhos, sabores e promoções.
- Mostra se a loja está aberta e quando abre.
- Consulta de entrega por bairro, com taxa e tempo.
- Carrinho e pagamento no PIX.
- O pedido vai montado para o WhatsApp da loja.
- Feito primeiro para o celular, que é onde o cliente pede.

## Tecnologia

HTML, CSS e JavaScript, sem framework, para abrir rápido em qualquer celular. Hospedado na Vercel. Cardápio, preços, bairros, horários e chave PIX ficam num arquivo de configuração, então um restaurante novo fica pronto em pouco tempo.
